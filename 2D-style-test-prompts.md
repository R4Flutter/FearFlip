# FearFlip 2D: one dashboard test prompt per style

Each prompt makes one complete dashboard screen (the main menu) in one style, with the same layout every time, so you
can compare the 9 looks side by side and pick one.

**How to test fairly**
- Use the same tool for all 9 (GPT Image or Ideogram; both spell the button words well) and the same size:
  portrait 9:16 (1080×1920, or 1024×1536 if that's the only portrait size).
- Make 2-3 images per style. AI varies a lot, so judge the best one of each.
- Look at them at phone size (zoom out), not only full screen.
- These are mockups to choose a style. The real game art is made piece by piece later from `2D-game-assets.md`.

**The layout in every prompt** (so only the style changes):
- Top bar: a round avatar with "AB", the name "PLAYER", a trophy icon with "1,234".
- The logo "FEAR FLIP" near the top.
- A big scene in the middle: the horned Devil looming over a maze, and the hero runner seen from behind.
- A big "START SURVIVAL" button.
- A 2×2 grid of buttons: "CHARACTER", "LEADERBOARD", "SETTINGS", "REMOVE ADS", each with an icon.
- A small "RANK #128" badge, then a thin empty banner-ad strip at the very bottom.

# Character test prompts, per style

The cast is the same in every style. Only how it's drawn changes:

| Character | Who | Must read as a silhouette |
|---|---|---|
| **Steel Sentinel** (default runner) | a compact survivor in dented steel armour, a rounded helmet with a narrow glowing visor slit, a small shoulder lamp, steel-blue accents | round helmet, broad shoulders |
| **Green Phantom** | a slender hooded wanderer in a long tattered cloak, the face hidden except two glowing green eyes, a lantern of green ghost fire | tall pointed hood, flared cloak |
| **Void Ripper** | a lean, agile runner in a high-collar jacket, short white hair, a half-mask, a long violet scarf, two short curved blades | blades and trailing scarf |
| **The Devil** | a tall hunched horned demon about twice the runners' height, long arms with hooked claws, burning red eyes | huge curved horns, long claws |

No runner wears red: red belongs to the Devil and to danger.

Each style has two prompts:
- **A, the lineup.** All 4 characters, full body, facing the viewer. Use it to judge the look.
- **B, the maze check.** The same 4 seen from above, small, the way they appear in the maze. Use it to check they're
  still readable. Shrink image B to about 300 px wide: if you can't tell the 4 apart, that style won't work in the
  maze.
